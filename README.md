# c2w_shopify_advanced
This is a advanced version of sopify project

Requirements:

Firebase Configuration

Generate the Firebase JSON configuration file.

Add the JSON file to the resources folder.

Cloudinary Configuration

Add the following credentials to com.core2web.config.CloudinaryConfig.java:

Cloud Name

API Key

API Secret

Groq API Configuration

Add the Groq API Key to com.c2w.controller.delivery.DeliveryAIAssistantController.java at line 27.

Razorpay Configuration

Add the following credentials to com.c2w.utils.Keys:

API Key
